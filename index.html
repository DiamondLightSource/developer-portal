Structure

The User Guide contains documentation on how to use the developer portal. This is split into four sub-sections:

  • Tutorials :link: provide worked examples for typical usage. New users should start here.

  • How Tos :link: provide step-by-step guides for more experienced users.

  • Explanations :link: provide insight into how the service works and why it works that way.

  • References :link: provide technical reference material including APIs and release notes.
